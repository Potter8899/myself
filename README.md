# Potter Portfolio (พอตเตอร์) - Minecraft 3D Modeler & Developer

เว็บไซต์พอร์ตโฟลิโอสำหรับรับทำโมเดล 3D Minecraft (Blockbench), มอด และงานพัฒนาซอฟต์แวร์ พร้อมระบบแชตสอบถามงาน แจ้งเตือน Discord อัตโนมัติ และรองรับฐานข้อมูล Supabase SQL แบบ Realtime

---

## 🌟 ฟีเจอร์หลักที่พัฒนาเพิ่ม

1. **แสดงรูปภาพคมชัดและลบรูปได้ (Gallery Management)**
   - ปรับการแสดงผลรูปภาพในแกลเลอรีให้เห็นอย่างชัดเจน สวยงาม มีแสงนีออนละมุน ไม่มืดทึบ
   - สามารถกดปุ่ม **"✕ ลบ"** ที่มุมขวาบนของแต่ละการ์ดรูปภาพ เพื่อลบรูปที่ไม่ต้องการได้ทันที
   - รองรับการอัปโหลดรูปภาพใหม่ผ่านปุ่ม "เลือกรูปเพิ่ม" หรือการลากรูปมาวาง (Drag & Drop)
   - จดจำรายการรูปภาพที่เพิ่ม/ลบไว้ใน `localStorage` อัตโนมัติ

2. **พื้นหลังจุดอวกาศสวยงาม (Cosmic Space Particles Background)**
   - พื้นหลังอวกาศแบบจุดดวงดาวระยิบระยับ (Twinkling Stars) หลายระดับความลึก
   - มีดาวตก (Meteors/Shooting Stars) พาดผ่านท้องฟ้าเป็นระยะ
   - รองรับ Parallax ตอบสนองตามการขยับเมาส์อย่างนุ่มนวล
   - เมื่อคลิกเมาส์จะมีประกายละอองดาว (Stardust) กระจายออก

3. **หน้าต้อนรับ/โหลดพร้อมเลือกชื่อและภาษา (Welcoming Onboarding)**
   - ดีไซน์การ์ดกระจกอวกาศ (Glassmorphism) สวยงาม น่าดึงดูด
   - ระบบตรวจสอบและป้องกันชื่อผู้ใช้งานซ้ำ (Duplicate Nickname Prevention)
   - ป้องกันการใช้ชื่อสงวนของระบบ (เช่น admin, potter)

4. **รองรับ 3 ภาษาเต็มรูปแบบ (Multi-Language: TH / EN / RU)**
   - **ไทย (TH)**
   - **อังกฤษ (EN)**
   - **รัสเซีย (RU)**
   - สลับภาษาได้ทั้งที่หน้าแรกและเมนูบาร์ด้านบน พร้อมจดจำภาษาของผู้ใช้ไว้ใน `localStorage`
   - แปลเนื้อหาครบถ้วน ทั้งหน้าแรก, ข้อมูลส่วนตัว, โปรเจกต์, บริการรับทำโมเดล, แกลเลอรี และระบบแชต

5. **เน้นบริการรับทำโมเดล Minecraft 3D (Blockbench)**
   - โปรโมทความเชี่ยวชาญการทำโมเดลบอส ม็อบ อาวุธ ชุดเกราะ และไอเทม
   - รองรับปลั๊กอินยอดนิยม: **ModelEngine, MythicMobs, ItemsAdder, Oraxen, Java & Bedrock**

6. **ขยายรูปโปรไฟล์ให้ใหญ่ขึ้น (Larger Hero Avatar)**
   - เพิ่มขนาดการ์ดรูปภาพโปรไฟล์ให้โดดเด่นสะดุดตา (ขนาด 360px)
   - กรอบนีออนอวกาศ ป้ายแท็ก 3D Modeler & Dev และเอฟเฟกต์คลิกดูรูปขนาดเต็ม

7. **ระบบแชตสอบถามงานในเว็บ (Live Inquiry Chat) + แยกแชตลูกค้า**
   - ลูกค้าสามารถพิมพ์สอบถามสั่งทำโมเดลหรือปรึกษางานได้ทันที
   - แยกห้องแชตของลูกค้าแต่ละคนตาม Session ID และ Username
   - บันทึกและจดจำประวัติการคุยไว้ (Chat Persistence)
   - มีปุ่ม **"ล้างประวัติแชต"** ให้ลูกค้าสามารถลบประวัติของตนเองได้

8. **แจ้งเตือนเข้า Discord Webhook อัตโนมัติ**
   - เมื่อมีผู้ใช้ส่งข้อความสอบถามในแชต ระบบจะส่ง Notification ไปยัง Discord Webhook:
     `https://discord.com/api/webhooks/1570097164334407695/...`
   - รูปแบบ Rich Embed สวยงาม แสดงชื่อผู้ติดต่อ, ข้อความ, ภาษา, Session ID และเวลา

9. **ระบบแอดมิน (Admin Mode & Reply)**
   - กดปุ่ม **"แอดมิน"** ที่มุมขวาบนของหน้าเว็บ
   - รหัสผ่านแอดมินเริ่มต้น: `potter2026`
   - แอดมินสามารถเปิดดูรายการแชตของลูกค้าทุกคน และคลิกเข้าไปตอบกลับในฐานะ `[ ADMIN ] พอตเตอร์` ได้โดยตรง

10. **รองรับ Supabase SQL & Realtime**
    - มีไฟล์ SQL สำหรับสร้างตารางและนโยบายความปลอดภัยพร้อมรัน: `supabase_setup.sql`
    - เมนูแอดมินมีแท็บตั้งค่า **Supabase URL & Anon Key**
    - หากเชื่อมต่อ Supabase ระบบจะซิงค์แชตแบบเรียลไทม์ (Realtime 2-way) ข้ามเครื่องทันที
    - หากยังไม่ได้เชื่อมต่อ Supabase ระบบจะทำงานในโหมด LocalStorage + Discord Webhook ได้อย่างสมบูรณ์แบบโดยไม่มีข้อผิดพลาด

11. **ดีไซน์เป็นมืออาชีพ ลดการใช้อิโมจิพร่ำเพรื่อ**
    - ใช้ฟอนต์ Prompt (สำหรับภาษาไทย) และ Inter (สำหรับสากลและรัสเซีย)
    - เส้นสายคมชัด สไตล์โมเดิร์นกึ่งไซเบอร์สเปซ เหมาะสำหรับนักพัฒนามืออาชีพ

## 🚀 วิธีนำขึ้นออนไลน์ (Deploy Online)

เว็บไซต์นี้เป็น Frontend แบบ Pure HTML, CSS และ JavaScript สามารถนำขึ้นออนไลน์ได้ฟรีทันที:

### ตัวเลือกที่ 1: Vercel (แนะนำ)
1. นำโฟลเดอร์นี้อัปโหลดขึ้น GitHub Repository
2. เข้าไปที่ [Vercel](https://vercel.com/) แล้วกด **Add New Project** -> เลือก Repo ของคุณ
3. กด **Deploy** เว็บไซต์จะออนไลน์ทันที

### ตัวเลือกที่ 2: GitHub Pages
1. สร้าง GitHub Repository เช่น `potter-portfolio`
2. Push ไฟล์ทั้งหมดขึ้น GitHub
3. ไปที่แท็บ **Settings** -> **Pages** -> เลือก Branch `main` แล้วกด Save

### ตัวเลือกที่ 3: Netlify / Cloudflare Pages
- เพียงลากโฟลเดอร์นี้ไปวางในหน้า Dashboard ของ Netlify หรือ Cloudflare Pages ก็พร้อมใช้งานทันที

## 🗄️ การติดตั้ง Supabase SQL

1. สมัครใช้งานหรือเข้าสู่ระบบที่ [Supabase](https://supabase.com/)
2. สร้าง New Project
3. ไปที่เมนู **SQL Editor** ทางแถบซ้ายมือ
4. เปิดไฟล์ `supabase_setup.sql` ในโฟลเดอร์นี้ คัดลอกโค้ดทั้งหมดแล้วนำไปวางใน SQL Editor ของ Supabase จากนั้นกด **Run**
5. ไปที่ **Project Settings** -> **API** คัดลอก:
   - **Project URL**
   - **Project API Keys (anon public)**
6. เปิดหน้าเว็บของคุณ -> กดปุ่ม **"แอดมิน"** (รหัสผ่าน `potter2026`) -> เลือกแท็บ **"Supabase & SQL Config"** -> วาง URL และ Anon Key แล้วกด **"บันทึก & เชื่อมต่อ"**
