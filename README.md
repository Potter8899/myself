# Potter Portfolio - Minecraft 3D Modeler & Discord Ticket Bot

ระบบพอร์ตโฟลิโอรับทำโมเดล 3D Minecraft (Blockbench) เชื่อมต่อระบบแชตตั๋วสอบถามงานสองทางกับ **Discord Bot (Python)** แบบ Real-Time พร้อมระบบสมัครสมาชิก ตรวจสอบอีเมล และระบบป้องกันบอท (Anti-Bot)

---

## 🚀 ฟีเจอร์ใหม่ที่พัฒนาเพิ่ม

1. **ระบบแชตสองทางผ่าน Discord Bot (Python แทน Webhook เดิม)**
   - **เมื่อลูกค้าพิมพ์ในหน้าเว็บ:** บอท Discord จะสร้างห้องตั๋วอัตโนมัติในหมวดหมู่ เช่น `#ticket-ชื่อลูกค้า` พร้อมส่งข้อความและข้อมูลลูกค้าเข้าไป
   - **เมื่อแอดมิน (พอตเตอร์) พิมพ์ตอบใน Discord:** ข้อความของคุณจะถูกส่งกลับไปยังหน้าแชตบนเว็บไซต์ของลูกค้าทันทีแบบ Real-Time พร้อมเครื่องหมายติ๊กถูก `✅` ยืนยันใน Discord
   - รองรับทั้ง WebSocket ความเร็วสูง และ REST API

2. **คำสั่ง Discord Slash Command `/setup`**
   - เมื่อพิมพ์คำสั่ง `/setup` ในเซิร์ฟเวอร์ Discord บอทจะสร้างโครงสร้างระบบตั๋วให้แบบอัตโนมัติทั้งหมด:
     - 📁 หมวดหมู่: `🎫 ตั๋วสอบถามงาน (Tickets)`
     - 📌 ห้องแผงควบคุม: `📌-จัดการระบบตั๋ว` (พร้อม Embed แนะนำการใช้งานและปุ่มควบคุม)
     - 📋 ห้องประวัติ: `📋-ประวัติข้อความ`

3. **คำสั่งปิดตั๋ว `/close` หรือกดปุ่ม 'ปิดตั๋วนี้'**
   - เมื่อคุยงานเสร็จแล้ว แอดมินสามารถกดปุ่มสีแดง **"🔒 ปิดตั๋วนี้ (Close Ticket)"** หรือพิมพ์คำสั่ง `/close`
   - ระบบจะแจ้งเตือนลูกค้าในหน้าเว็บว่าตั๋วถูกปิดแล้ว และนับถอยหลังลบห้องตั๋วนั้นใน Discord อัตโนมัติใน 5 วินาที

4. **ระบบบัญชี ตรวจสอบชื่อซ้ำ รหัสผ่าน และอีเมล**
   - **กันชื่อซ้ำ:** ตรวจสอบชื่อผู้ใช้แบบ Real-Time ไม่ให้ซ้ำกับคนอื่น และห้ามใช้ชื่อสงวนของระบบ
   - **รหัสผ่าน:** กำหนดรหัสผ่านขั้นต่ำ 6 ตัวอักษร เพื่อให้ลูกค้าสามารถกลับมาล็อกอินเข้าดูตั๋วเดิมได้
   - **ตรวจสอบอีเมล:** ตรวจสอบรูปแบบอีเมลที่ถูกต้อง (Regex Validation)

5. **ระบบป้องกันบอท (Anti-Bot Challenge)**
   - **Math Challenge:** ระบบสุ่มโจทย์คำนวณตัวเลขแบบไดนามิก (เช่น `5 + 3 = ?`) เพื่อยืนยันตัวตนว่าไม่ใช่บอท
   - **Honeypot Trap:** มีช่องกรอกข้อมูลลับที่มองไม่เห็น หากเป็นสคริปต์บอทอัตโนมัติที่พยายามกรอกฟอร์ม ระบบจะบล็อกทันที

6. **แอดมินตอบแชตและจัดการผ่าน Discord 100%**
   - พอตเตอร์ไม่ต้องเข้าสู่ระบบในเว็บให้ยุ่งยากอีกต่อไป จัดการและคุยงานผ่าน Discord บนมือถือหรือคอมพิวเตอร์ของคุณได้เลย

## 🛠️ วิธีติดตั้งและเปิดใช้งาน Discord Bot

### ขั้นตอนที่ 1: รับ Bot Token จาก Discord
1. เข้าไปที่ [Discord Developer Portal](https://discord.com/api/oauth2/authorize) -> [Applications](https://discord.com/developers/applications)
2. กด **New Application** ตั้งชื่อ เช่น `Potter Ticket Bot`
3. ไปที่เมนู **Bot** ทางซ้ายมือ:
   - กด **Reset Token** แล้วกดคัดลอก (Copy) Token มา
   - เลื่อนลงมาที่หัวข้อ **Privileged Gateway Intents** -> ติ๊กเปิด **MESSAGE CONTENT INTENT** (สำคัญมากเพื่อให้บอทอ่านข้อความตอบกลับได้)
4. ไปที่เมนู **OAuth2** -> **URL Generator**:
   - ในช่อง Scopes เลือก: `bot`, `applications.commands`
   - ในช่อง Bot Permissions เลือก: `Administrator` หรือเลือก `Manage Channels`, `Send Messages`, `Read Message History`, `Add Reactions`
   - คัดลอก URL ด้านล่างนำไปเปิดในเบราว์เซอร์เพื่อดึงบอทเข้าเซิร์ฟเวอร์ Discord ของคุณ

### ขั้นตอนที่ 2: ใส่ Token ในไฟล์ `.env`
เปิดไฟล์ `.env` ในโฟลเดอร์นี้ แล้วนำ Token มาวาง:
```env
DISCORD_TOKEN=your_token_here
DISCORD_GUILD_ID=your_server_id (ใส่ ID เซิร์ฟเวอร์เพื่อให้คำสั่ง /setup ใช้ได้ทันที)
PORT=5000
```
*(วิธีดู Server ID: ใน Discord ไปที่ Settings -> Advanced -> เปิด Developer Mode -> คลิกขวาที่ชื่อเซิร์ฟเวอร์แล้วกด 'Copy Server ID')*

### ขั้นตอนที่ 3: เริ่มรันบอท
สามารถเปิดใช้งานได้ง่ายๆ ด้วยวิธีใดวิธีหนึ่ง:
* **ดับเบิ้ลคลิกที่ไฟล์:** `run_bot.bat` (มีระบบตรวจสอบและติดตั้งแพ็กเกจให้อัตโนมัติ)
* **หรือสั่งผ่าน Command Line:**
  ```powershell
  python bot.py
  ```

### ขั้นตอนที่ 4: ตั้งค่าใน Discord
1. ในเซิร์ฟเวอร์ Discord พิมพ์คำสั่ง:
   ```
   /setup
   ```
2. บอทจะสร้างหมวดหมู่ตั๋วและห้องแผงควบคุมให้ทันที
3. เมื่อเปิดหน้าเว็บ [`index.html`](file:///f:/myself/index.html) และมีคนพิมพ์ข้อความในแชต บอทจะสร้างห้อง `#ticket-ชื่อลูกค้า` ให้คุณเข้าไปพิมพ์คุยได้ทันที!
