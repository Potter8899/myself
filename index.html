บริการรับทำโมเดล & รับงาน

โมเดล Minecraft 3D (Blockbench) รับทำโมเดลบอส ม็อบ สัตว์ อาวุธ ชุดเกราะ ไอเทม และเฟอร์นิเจอร์ พร้อมแอนิเมชันโจมตี/เดิน รองรับ ModelEngine, MythicMobs, ItemsAdder, Java & Bedrock
มอดและปลั๊กอิน Minecraft พัฒนา Forge / Fabric mod, Spigot / Paper plugins, ระบบเควสต์, ระบบร้านค้า และกลไกเฉพาะทางสำหรับเซิร์ฟเวอร์
พัฒนาเว็บไซต์ & เว็บร้านค้า ทำเว็บพอร์ตโฟลิโอ เว็บร้านค้าไอเทมเกม ออกแบบ UI ทันสมัย รองรับมือถือและคอมพิวเตอร์
แอป Android & ซอฟต์แวร์ Windows พัฒนาโปรแกรมเครื่องมือเฉพาะทาง แอปพลิเคชันด้วย Kotlin และเครื่องมือเชื่อมโยงข้อมูล
สคริปต์ & Discord Webhook Bot เขียนสคริปต์ Python ทำงานอัตโนมัติ ระบบบอทแจ้งเตือนเข้า Discord และการเชื่อมต่อฐานข้อมูล

สนใจสั่งงานหรือต้องการสอบถามประเมินราคา สามารถกดทักแชตในหน้านี้ได้เลยครับ

}
